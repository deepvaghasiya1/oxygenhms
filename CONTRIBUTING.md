# Contributing to OxygenHMS

We love your input! We want to make contributing to OxygenHMS as easy and transparent as possible.

## Development Process

1. Fork the repo and create your branch from `main`
2. If you've added code that needs testing, add tests
3. Ensure your code follows our style guide
4. Make sure your code passes linting checks
5. Submit a pull request

## Pull Request Process

1. Update the README.md with details of changes to the interface
2. Update the CHANGELOG.md with notes on your changes
3. Ensure all tests pass
4. Request review from maintainers

## Coding Standards

- Use ESLint for JavaScript
- Follow existing code style
- Comment complex logic
- Write meaningful commit messages
- Test your changes

## Reporting Bugs

Use the GitHub issue tracker to report bugs. Include:
- Clear description
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots if applicable

## Feature Requests

Submit feature requests as GitHub issues with:
- Clear use case
- Expected behavior
- Why it would be useful

## Questions?

Feel free to open an issue or contact the maintainers.
